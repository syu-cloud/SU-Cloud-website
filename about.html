ABOUT

Cloud Lab을
소개합니다

CLOUDLAB은 삼육대학교 컴퓨터공학부의 클라우드 연구팀입니다. 교내 유휴 서버를 활용한 프라이빗 클라우드(OpenStack) 구축·운영부터 퍼블릭 클라우드 위에서의 MSA 인프라 설계, MLOps 파이프라인 자동화, 실시간 데이터 파이프라인 구축까지 — 학부생이 직접 인프라를 설계하고 운영하며 연구합니다.

연구 결과는 학술 논문으로 이어집니다. 한국컴퓨터정보학회 논문지에 실시간 데이터 파이프라인 최적화, 로그 인코딩, 클라우드 자원 수명주기 자동화 연구를 게재했으며, Kakao Enterprise와 협력해 KakaoCloud 공식 교육 자료를 직접 제작했습니다.

멤버가 되면 교수님 지도와 멘토-멘티 세션 아래 진행 중인 실전 프로젝트에 합류하게 되며, 비용 부담 없이 실습할 수 있는 프라이빗 서버 인프라를 제공합니다.

클라우드 인프라와 데이터 엔지니어링에 열정이 있다면 전공과 학년에 관계없이 환영합니다.

OUR DIRECTION

기술보다 먼저,
함께 배우는 방식.

Cloud Lab 클라우드와 웹, 데이터, 보안 등 다양한 기술을 직접 실습하고 프로젝트로 확장합니다.

개인의 학습을 팀의 경험으로 연결하고, 결과물을 만들며 성장하는 과정을 중요하게 생각합니다.

01

Cloud-Native MSA & DevOps

VPC 네트워크 설계부터 Kubernetes 기반 배포 자동화, HPA 오토스케일링까지 엔터프라이즈 인프라의 전체 라이프사이클을 다룹니다.

#KakaoCloud #Kubernetes #Helm
02

Real-Time Data Pipeline

Nginx–Filebeat–Logstash–Kafka–Spark–Hive로 이어지는 대규모 파이프라인의 End-to-End 지연 시간을 밀리초 단위로 분해 측정하고, 지연·처리량·안정성 간 상충관계를 최적화합니다.

#Kafka #SparkStreaming #ElasticStack
03

End-to-End MLOps Pipeline

Kubeflow를 활용한 GPU 학습 환경 구성, 모델 학습·서빙, 하이퍼파라미터 튜닝 등 AI 엔지니어링 파이프라인을 자동화합니다.

#Kubeflow #KServe #Docker
04

On-Premise Private Cloud

교내 유휴 물리 서버로 학생 실습용 가상화 환경을 직접 구축·운영합니다. 상용 클라우드를 대체하는 무료 프라이빗 클라우드 인프라입니다.

#OpenStack #PrivateCloud #Virtualization
